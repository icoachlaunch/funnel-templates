For Your Clients
The vibe coding shortcut

Every template comes with a prompt at the bottom of the HTML file. Clients copy it, fill in their [BRACKETS], paste it into Claude or ChatGPT, and get back a complete page in their voice — same visual design, their content. No design skills. No coding. Under 5 minutes.

Create a single-file HTML landing page for a free live masterclass opt-in / registration page. Use this exact visual style: DESIGN RULES (do not deviate): - Dark background (#111111) with a subtle crimson grid texture - Only font: Montserrat from Google Fonts (400, 500, 700, 900) - Only accent color: crimson #db0063 (hover: #a8004b) - All headlines: uppercase, font-weight 900, letter-spacing -0.02em - Cards: #1a1a1a, 1px solid #2b2b2b border, 4px radius max - Buttons: crimson fill, white text, weight 900, 2px radius, no shadows - No emoji. Numbers must always be specific — never vague. PAGE STRUCTURE (in this order): 1. Sticky header — logo + "Reserve My Spot →" link 2. Hero — eyebrow pill, h1, sub copy, pull quote, CTA button 3. Stats row — 4 real numbers (one highlighted with crimson top border) 4. Two-column: left = 5-item outcome checklist; right = sticky reg form 5. Testimonials — 2×2 grid (quote + name + role) 6. Closing urgency banner + repeat CTA 7. Footer — logo, tagline, copyright, privacy/terms links CONTENT TO INSERT: - Brand name: [YOUR BRAND NAME] - Event name: [YOUR MASTERCLASS TITLE] - Format: [e.g., Free · Live · 90 Min] - Date/time: [e.g., Thursday · 7pm EST] - Headline: [lead with the outcome] - Sub copy: [start with reader's pain, end with your promise] - Pull quote: [your most dramatic specific result] - Stat 1: [label / value / sub-label] - Stat 2 (highlight): [label / value / sub-label] - Stat 3: [label / value / sub-label] - Stat 4: [label / value / sub-label] - Checklist items 1–5: [specific outcomes] - Testimonials 1–4: [quote / name / role] - CTA button text: [action phrase] - Footer tagline + copyright: [your details] OUTPUT: One complete self-contained HTML file. No external CSS. No frameworks. Include a placeholder form handler comment at the bottom explaining GoHighLevel / ConvertKit / Zapier wiring options.
Publishing
Go live on GitHub Pages
in under 5 minutes
01
Fork or download this repo — click the green Code button on GitHub, then Download ZIP. Or fork it directly to your own account.
02
Edit the template files — open any index.html in a text editor (VS Code is free). Search EDIT: to jump to every placeholder.
03
Push back to GitHub — commit your changes and push to your repo's main branch.
04
Enable GitHub Pages — go to your repo Settings → Pages → Source: main branch, / (root). Your page goes live in under 60 seconds.
05
Point your domain (optional) — add a CNAME file with your domain name and update your DNS. GitHub Pages supports custom domains free.
